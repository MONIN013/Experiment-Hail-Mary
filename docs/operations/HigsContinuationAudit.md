# HIGS 実験の継続検証（2026-11-13）

対象は `feat/higs-experiment`、検証開始時のコミットは `b05ac58f4926b9f6164a7bb206fdf26ea1a5cd50` である。既存の実験と制御係数を維持し、元データの回収、再同定、実 C++ コアによる再検証、試行の合否判定の修正を行った。

## 1. 結論と修正

既定の HIGS は標準往復の追従誤差を減らす一方、整定区間や初期変位応答を悪化させる。したがって「線形制御器より常に高性能」とは判断しない。初回の比較候補は変更せず、線形比較器の目標交差 8 Hz、代表 LPF の折点 20 Hz、HIGS 一つ、通常の PI 積分器を残す構成を維持した。

`exp05_Higs.m` は、実測電流のピークを計算・保存していたものの、`result.accepted` に含めていなかった。指令が小さくても実測電流が上限に達した試行を合格にできるため、次の三つをすべて確認する `experiment.higs_current_accepted` に切り出した。

- 飽和前の制御入力のピーク `command_peak_a`
- DriverAdapter の電流指令のピーク `current_peak_a`
- 実測電流のピーク `measured_current_peak_a`

すべてが有限・実数・非負のスカラーで、設定上限 **未満** のときだけ合格にする。欠損・空配列・NaN・Inf・複数要素は不合格とする。ログを先に保存する流れは変えていない。

これは **試行終了後の採否判定** であり、過電流をリアルタイムで遮断する機能ではない。ドライブの過電流保護、PDO 換算、実電流の信号対応を別途確認する必要がある。C++ 制御コア、係数、PDO/TMC レイアウト、既存の実験入口はこの継続作業では変更していない。

## 3. 閉ループの再検証

実際の `ControllerAlgorithm.cpp` と `higs_host.cpp` を改変せずコンパイルした。取得したソースとローカルコピーの Git blob SHA も一致させた。条件は8 kHz、連続プラントの厳密 ZOH 離散化、明示的な2標本遅延、電流刻み1.6 mA、23 bit相当の角度量子化である。これらは現行コードを参照した **仮定** であり、実機の確定値ではない。

標準軌道は0.1 radの往復、各移動0.1秒、途中保持0.2秒、開始・終了の保持各0.4秒とした。以下は実機結果ではなく、このモデルによる結果である。

| 指標 | 線形 | HIGS | 評価 |
|---|---:|---:|---|
| 標準往復の誤差 RMS | 12.2259 mrad | 11.5969 mrad | 5.145%減少 |
| 最終0.2秒の誤差 RMS | 5.7984 mrad | 6.0395 mrad | 約4.16%増加 |
| 標準往復の最大誤差 | 42.6544 mrad | 38.5798 mrad | 減少 |
| 標準往復の印加電流ピーク | 20.8 mA | 24.0 mA | 増加 |
| 初期変位0.005 radからの復帰：6秒全体の誤差 RMS | 0.25055 mrad | 0.32494 mrad | 29.690%増加 |
| 0.001 rad往復の誤差 RMS | 0.51200 mrad | 0.51756 mrad | 1.086%増加 |
| 多周波参照の誤差 RMS | 10.0031 mrad | 9.6269 mrad | 3.762%減少 |

慣性二つと剛性をそれぞれ±20%、軸間粘性と接地粘性をそれぞれ±50%、明示的遅延を1・4・8標本とする96組でも比較した。両制御器とも設定した運動・電流範囲内で、標準往復のRMS減少は **4.362〜8.453%** であった。線形比較器の状態遷移行列のスペクトル半径は全96組で1未満、最大感度の最悪値は **1.84544**。通常条件・振幅変更・初期値・外乱・遅延追加など20組を合わせ、116組の比較結果を保存した。有限の条件集合に対する確認であり、不確かさ集合全体への保証ではない。

代表折点6通りと前置LPF4通り、計24候補も評価した。折点5 Hzと前置20/40 Hzの2候補は電流飽和を起こし、不採用とした。例えば前置20 Hzでは、RMSが10.649 mradまで下がって見えるが、飽和前電流要求は約197 mAで80 mAの基準を超える。折点10 Hz・前置なしはRMS11.436 mradまで下がる一方、要求電流ピークが約29.6 mAに増え、整定・初期値応答の問題も解消しなかった。単一のRMSだけで選定せず、既定20 Hzの比較候補を維持した。最適値だと主張するものではない。

## 4. 書籍との対応と設計上の知見

書籍 *Hybrid Integrator-Gain Systems: Analysis, Design and Applications* の§8.4.1、図8.7、式(8.11)は、HIGSの前後に重み付けフィルタを置き、`V=H^-1 C*` で目標の線形特性へ対応させる構成である。今回の実装はこの考え方を **LPFの一部をHIGS一つで置き換える構成** に適用したもので、図8.9の二つのHIGSを持つPID全体の再現ではない。

HIGSを代表LPF `H` に置き換えた合成特性が線形比較器に戻ることを、離散時間の1万周波数点で確認した。最大相対差は **1.71×10^-14** だった。HIGS単体のDCゲインは有限であるため、通常のPI積分器はHIGSの後段に残した。これは一定外乱を保持して補償するために必要で、書籍§3.5.1および§8.4.2の配置の議論に対応する。

離散時間則は§2.4、式(2.43)〜(2.44)の候補値判定を優先するtrimodal則である。候補の区間射影を独立の照合式にして90万標本を検査し、積分・ゲイン・ゼロ化の全モードを通過した。符号反転時でも候補が区間内なら積分モードを優先する境界例、設定拒否時の状態保持、reset、SOS/HIGS/FFの順序、HIGS無効時の線形動作も確認した。

今回の計算から得た重要な点は、(1) 前置フィルタを足すだけでは改善せず、逆フィルタによる電流要求も見ること、(2) 全区間RMSと整定性能を分けること、(3) 記述関数の位相改善を、そのまま任意入力に対する性能保証と解釈しないことである。書籍の§8.5.1〜8.5.2も入力の周波数構成と近似誤差を扱っているが、ここに示した数値は本装置モデルでの計算であり、書籍の実験値ではない。

## 5. 再現コマンドと実機に残る条件

リポジトリのルートから実行する。

```sh
python simulations/audit_higs.py
python simulations/audit_chirp.py --input /path/to/chirp_result.mat
g++ -std=c++17 -O2 -Wall -Wextra -Werror -IControllerCore ControllerCore/ControllerAlgorithm.cpp simulations/higs_regression.cpp -o higs_regression
./higs_regression
```

実行環境では上記C++検査に加えてundefined-behaviour sanitizerも有効にして通過した。Pythonの構文検査とシミュレーションも通過した。MATLABの `TestHigsCurrentAcceptance` は6メソッドを追加したが、MATLAB本体での実行はこの環境では行っていない。Windows/TwinCAT SDKでの再ビルドと実モータ運転も実施していない。

実機反映の詳細は既存の [HigsExperiment.md](HigsExperiment.md) を使用する。特に以下は計算だけでは確定しない。

1. `ExperimentHailMary.RealMotor.tsproj` の空のI/O定義へ実際のEtherCAT構成を取り込み、11個の仮PDOリンクを実信号へ接続する。`target_label` は記録用名称で、実機/VMの切替機能ではない。
2. counts/rev、符号、位置・速度・電流単位、動作モード、ドライブ保護、通信断時の停止を現物で確認する。旧ログは20 bit相当、現行既定は23 bitであり、推測でどちらかへ変更しない。80 mA等の値は今回の試行基準で、機械の定格・安全許容値を代替しない。
3. 現行8 kHz条件で測定し直した `plant.mat` を用意し、線形制御器の小振幅試行からHIGSとの同一軌道比較へ進む。旧同定の入力振幅0.5 Aに対して今回の標準試行は約20〜24 mAであり、小電流域の摩擦や量子化の影響も確認する。

プレビューは通電しない。ソフトウェア検証の通過だけを根拠に、I/O定義や物理的停止系の確認を省略してはならない。
