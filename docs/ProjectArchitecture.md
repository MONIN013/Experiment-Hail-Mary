# プロジェクト設計仕様
本プロジェクトの最終目標は、
**MATLAB / Simulink + TwinCAT を用いた 8kHz トルク制御実験環境において、Build回数を極限まで削減しつつ、再現性と同期性を保証する実験基盤を確立すること**である。

---

## 1. 技術的目標

### 1.1 周期同期性の保証

* 8kHz 制御周期で完全に完結するリアルタイム構造を確立する
* 異時刻信号混在を排除する
* EtherCAT DC とタスク構成を整合させる

### 1.2 Build依存性の排除

* 制御構造を固定化する
* パラメタ更新のみで実験条件変更を可能にする
* TE1400 を使用せず、C++ TcCOM で制御構造を直接実装する

### 1.3 層分離の徹底

* TwinCAT：リアルタイム制御専任
* MATLAB：実験統括・解析専任
* RTと非RTの責任を混在させない

---

## 2. 実験基盤としての目標

### 2.1 再現性の確保

* 実験条件を完全に再現可能にする
* 制御周期の揺らぎを排除する

### 2.2 同定・周波数応答測定の信頼性向上

* FRF歪みを防止する
* ILC収束性を保証する
* 注入信号の位相整合を保証する

### 2.3 安全性の確保

* Mode Managerによる状態管理
* Status Wordの適切なフィードバック
* Control Wordの責任分離

---

## 3. 設計上の制約条件

* 制御周期：8kHz 固定
* リアルタイム層はMATLABに依存しない
* ADS通信は非同期補助のみ
* 実験用途（長期保守前提ではない）

---

## 4. 本プロジェクトの本質

本プロジェクトは単なる制御実装ではない。

目的は、

* 実験系の物理的妥当性を保証し
* 同期性を破壊する設計を排除し
* 制御理論評価に耐えるデータを取得できる環境を構築する
